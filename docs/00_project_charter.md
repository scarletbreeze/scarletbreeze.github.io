# 00. Project Charter

## 한 문장
Hero Lab은 "증권업과 투자 생태계는 어떻게 작동하는가?"를 탐구하는 개인 연구소 사이트다.

## 왜 만드는가
- 회사에서 3개월간 지원받은 AI 도구로 **실제 결과물**을 만든다.
- 증권업·투자 생태계를 일반인이 이해할 수 있는 형태(시각화·인터랙션·게임)로 보여준다.
- 임원 대상 5분 발표/시연이 가능한 수준까지 완성한다.
- 이후 몇 년간 확장 가능한 개인 Research OS / Second Brain의 기반을 만든다.

## 기간
2026-09 초 ~ 2026-11 말 (약 12주)

## 사이트가 동시에 수행하는 역할
개발 블로그 · 투자/증권업 연구노트 · 데이터 시각화 · 인터랙티브 실험 · 게임 · 포트폴리오 · 아카이브

## 5개 프로젝트
1. **Hero Lab** — 사용자 유형별(초보/ETF/미국주식/단타/선물옵션) 영웅문 화면·기능 큐레이션
2. **VOC Studio** — 고객게시판 질문·불편·개선요구 분석 (초기엔 Mock/공개 데이터)
3. **Broker Atlas** — 증권사 수익구조(Brokerage/WM/IB/S&T/이자/대차/ETF LP/해외/FX) 시각화
4. **Time Machine Investor** — 과거 시점 투자 시뮬레이션 + 벤치마크 비교 + 공유 화면
5. **Broker Tycoon** — 자본을 사업부에 배분해 매출/비용/ROE/Risk가 달라지는 경영 시뮬레이션

## 성공 기준
- **Product**: 실제 URL 접속, 모바일 대응, 핵심 기능 동작, 5개 프로젝트가 한 사이트 안에서 자연스럽게 연결
- **Engagement**: (가능하면) 방문·사용·공유·재방문 측정. Time Machine과 Tycoon은 공유 기능 중시
- **Presentation** (가장 중요): 5분 안에 무엇을/왜/어떤 문제를/무엇을 만들었고/AI를 어떻게 썼고/어떻게 확장할지 설명

## 제약
- 공개 데이터만 사용. 회사 내부 데이터 금지.
- 정적 호스팅(GitHub Pages) 우선. 서버는 필요해질 때.
- AI 기능은 데이터·UX가 갖춰진 뒤 레이어로 추가.
