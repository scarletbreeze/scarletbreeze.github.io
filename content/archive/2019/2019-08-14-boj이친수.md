## 이친수

- ![No Image](/legacy/assets/posts/20190814/2.png)

```python
import sys
input = sys.stdin.readline
N = int(input())
d = [0, 1, 1]+[0]*(N-2)
for i in range(3, N+1):
    d[i] = d[i-1]+d[i-2]
print(d[N])
```
